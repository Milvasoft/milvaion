Milvaion {{ .Chart.AppVersion }} is installed as release "{{ .Release.Name }}" in namespace "{{ .Release.Namespace }}".

{{- if .Values.ingress.enabled }}

Dashboard and API:
{{- range .Values.ingress.hosts }}
  http{{ if $.Values.ingress.tls }}s{{ end }}://{{ .host }}{{ (first .paths).path }}
{{- end }}
{{- else }}

Reach the dashboard and API with a port-forward:
  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "milvaion.api.fullname" . }} 5000:{{ .Values.api.service.port }}
  then open http://localhost:5000
{{- end }}

Sign in as "rootuser". The password is in the Secret:
{{- if .Values.auth.existingSecret }}
  kubectl --namespace {{ .Release.Namespace }} get secret {{ .Values.auth.existingSecret }} -o jsonpath="{.data.{{ .Values.auth.secretKeys.rootPassword }}}" | base64 -d
{{- else }}
  kubectl --namespace {{ .Release.Namespace }} get secret {{ include "milvaion.secretName" . }} -o jsonpath="{.data.{{ .Values.auth.secretKeys.rootPassword }}}" | base64 -d
{{- end }}
It is applied only when the database is first initialised; change it in the dashboard afterwards.

The API applies database migrations when it starts. Watch the first start with:
  kubectl --namespace {{ .Release.Namespace }} logs deploy/{{ include "milvaion.api.fullname" . }} -f
